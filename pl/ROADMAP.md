# Plan rozwoju — Vermyx

Roadmapa ma wspierać regularną naukę, a nie wyścig po liczbę ukończonych pokoi.

## Etap 1 — fundamenty
- [ ] Powtórzyć TCP/IP, DNS, HTTP/HTTPS, routing i podstawy TLS.
- [ ] Ćwiczyć Linux CLI: pliki, uprawnienia, użytkownicy, procesy, usługi i logi.
- [ ] Rozumieć wyniki Nmapa: stan portu, wykrywanie wersji i ograniczenia skanowania.
- [ ] Notować każdą komendę razem z celem i interpretacją wyniku.

## Etap 2 — praktyka laboratoryjna
- [ ] Rozwiązać wybrane pokoje ponownie bez zaglądania do write-upów.
- [ ] Dla każdej techniki zapisać warunki działania i możliwe przyczyny niepowodzenia.
- [ ] Uzupełnić notatki o perspektywę defensywną: logi, detekcja i naprawa.
- [ ] Ćwiczyć podstawy web: żądania HTTP, cookies, sesje, kontrola dostępu i walidacja wejścia.

## Etap 3 — własne projekty
- [ ] Stworzyć mały skrypt Python do parsowania i porządkowania logów lub wyników skanowania.
- [ ] Opisać projekt: problem, zakres, sposób działania, testy i ograniczenia.
- [ ] Rozwijać prototyp analizy relacji między encjami z wykorzystaniem Python/FastAPI/Neo4j wyłącznie na danych testowych lub legalnie pozyskanych.
- [ ] Dodać instrukcję uruchomienia oraz przykładowe, niesensytywne dane.

## Etap 4 — specjalizacja
- [ ] Pogłębiać OSINT: wiarygodność źródeł, korelacja i odtwarzalność ustaleń.
- [ ] Poznać podstawy analizy incydentów i raportowania ustaleń.
- [ ] Budować portfolio oparte na jakości notatek i własnych projektach, nie samych odznakach.

## Kryterium ukończenia

Temat uznaję za utrwalony, gdy potrafię wyjaśnić go własnymi słowami, odtworzyć ćwiczenie w autoryzowanym środowisku i wskazać ograniczenia oraz wnioski obronne.
