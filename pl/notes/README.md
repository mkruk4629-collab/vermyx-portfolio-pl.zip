# Notatki techniczne

W tym katalogu umieszczam własne notatki edukacyjne, które tłumaczą mechanizmy, a nie tylko podają gotowe odpowiedzi.

## Zasady dobrych notatek
- Opisuję kontekst i zakres autoryzowanego laboratorium.
- Zapisuję komendy wraz z wyjaśnieniem argumentów.
- Rozdzielam obserwacje, hipotezy i potwierdzone wnioski.
- Dodaję aspekt defensywny: logowanie, wykrywanie i naprawę.
- Nie publikuję flag, sekretów ani treści naruszających zasady pokoju.

Nowe notatki tworzę na podstawie [szablonu](../templates/LAB_NOTE_TEMPLATE.md).
