# Learning Roadmap — Vermyx

This roadmap prioritizes consistent learning over collecting room completions.

## Stage 1 — fundamentals
- [ ] Review TCP/IP, DNS, HTTP/HTTPS, routing and TLS basics.
- [ ] Practise Linux CLI: files, permissions, users, processes, services and logs.
- [ ] Understand Nmap output, version detection and scan limitations.
- [ ] Document each command with its purpose and interpretation.

## Stage 2 — lab practice
- [ ] Revisit selected rooms without relying on walkthroughs.
- [ ] Document prerequisites, why a technique works and common failure causes.
- [ ] Add defensive context: logging, detection and remediation.
- [ ] Practise web fundamentals: HTTP requests, cookies, sessions, access control and input validation.

## Stage 3 — personal projects
- [ ] Build a small Python utility to parse and organize logs or scan output.
- [ ] Document the problem, scope, implementation, tests and limitations.
- [ ] Develop a prototype for entity relationship analysis with Python/FastAPI/Neo4j using test data or lawfully obtained data only.
- [ ] Include setup instructions and non-sensitive sample data.

## Stage 4 — focus areas
- [ ] Deepen OSINT skills: source reliability, correlation and reproducibility.
- [ ] Learn incident-analysis and reporting fundamentals.
- [ ] Build a portfolio around the quality of notes and original projects, not badges alone.

## Completion criterion

A topic is consolidated when I can explain it in my own words, reproduce the exercise in an authorized environment, and describe its limitations and defensive implications.
