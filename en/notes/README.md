# Technical notes

This directory is for original learning notes that explain mechanisms instead of merely listing answers.

## Note-taking principles
- Describe the context and authorized scope.
- Explain commands and their arguments.
- Separate observations, hypotheses and verified conclusions.
- Include defensive context: logging, detection and remediation.
- Never publish flags, secrets or content that violates room rules.

Use the [lab note template](../templates/LAB_NOTE_TEMPLATE.md) for new notes.
