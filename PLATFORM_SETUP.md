# Jak wykorzystać pliki / How to use these files

## Repozytorium portfolio
To repozytorium jest stroną startową z odnośnikami do wersji polskiej i angielskiej. Obie wersje znajdują się w katalogach `pl/` i `en/`.

## README profilu GitHub
Aby ustawić stronę główną profilu, utwórz publiczne repozytorium o nazwie dokładnie takiej jak Twój login GitHub. Skopiuj zawartość `github-profile/README_PL.md` albo `github-profile/README.md` do głównego `README.md` tego repozytorium. GitHub nie obsługuje automatycznie dwóch języków w jednym profilu; wybierz jeden język i połącz go z drugą wersją.

## Bio
Skopiuj wybraną linię z `github-profile/BIO.md` do pola Bio w ustawieniach profilu GitHub.

## Uwaga
Statystyki są statycznym snapshotem dostarczonym przez właściciela profilu. Aktualizuj je ręcznie. Przed publikacją przejrzyj notatki i usuń sekrety, flagi oraz informacje, których publikacja jest zabroniona przez zasady laboratorium.
